# Security Policy

## Supported Versions

We only provide security updates for the **latest stable release** available on the [Releases page](https://github.com/theesmaeil1/bale-bot-course/releases).

| Version | Supported |
| ------- | ------------------ |
| Latest release (from GitHub Releases) | ✅ |
| Any previous release or `main` branch code not yet released | ❌ |

> **Note:** Always download the latest release package (`Source code.zip`) from the [Releases section](https://github.com/theesmaeil1/bale-bot-course/releases) to ensure you have the most recent security fixes.

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability within the course code, examples, or any related script, please follow these steps:

1. **Do not** open a public issue on GitHub.
2. Send an email to **security@viraigame.ir** (or use the contact form on [viraigame.ir](https://viraigame.ir)).
3. Provide as much detail as possible:
   - Description of the issue
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

You can expect an initial response within **48 hours**.  
We will keep you informed about the progress and will publicly credit you (if desired) after a fix is released.

## Scope

This policy applies to:
- All Python code provided in the `bale-bot-course` repository (specifically the latest release package)
- Code snippets and downloadable files included in the latest release

Note: The course content (videos, documentation, and educational text) is not subject to security vulnerability reports, but we appreciate any feedback.

## Preferred Languages

We prefer to communicate in **English** or **Persian** regarding security issues.

Thank you for helping keep this open‑source course safe for everyone.
