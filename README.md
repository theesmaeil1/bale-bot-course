## 🚀 شروع سریع

### 1️⃣ کلون کردن مخزن

```bash
git clone https://github.com/theesmaeil1/bale-bot-course.git
cd bale-bot-course
```

### 2️⃣ ساخت محیط مجازی (پیشنهادی)

```bash
python -m venv venv
```

فعال‌سازی:

- ویندوز:
```bash
venv\\Scripts\\activate
```

- لینوکس / مک:
```bash
source venv/bin/activate
```

### 3️⃣ نصب کتابخانه رسمی بله

```bash
pip install balebot
```
